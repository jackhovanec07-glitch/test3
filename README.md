# Jack Hovanec — Portfolio

A simple personal portfolio site (plain HTML + CSS, no build step), hosted on GitHub Pages.

- `index.html` — the page content (edit text here)
- `style.css` — colors and layout (change `--accent` at the top to change the theme color)

To update the live site: edit the files, then run `git add .`, `git commit -m "update"`, `git push`.
